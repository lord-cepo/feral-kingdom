# Project file guide

Runtime asset cleanup (2026-11-05): [assets/README.md](../assets/README.md) is
the current directory map and loader caller guide. Original character frames,
legacy high-resolution card art and unused loose images/imports are no longer
shipped or retained locally. Older source-directory descriptions below record
import history; runtime characters use only `assets/characters/sheets/`.
Editable PXO projects live locally outside resources in ignored `art-source/`.
`tools/audit_runtime_assets.py` performs a read-only dependency/animation audit.

`relay/` is the independently deployable Cloudflare lobby/message relay. It is
excluded from Godot import with `.gdignore`. See `relay/README.md` and
`relay/PROTOCOL.md` for setup, wire contracts, caller maps and limitations. It
contains no gameplay rules. `scripts/network/network_session.gd` is the persistent
Godot autoload transport/host-authority adapter; `scripts/ui/network_lobby.gd`
connects Host/Find and saved-army Ready/start. `network_build.gd` is generated by
`tools/generate_network_fingerprint.py` before client export. See
[MULTIPLAYER.md](MULTIPLAYER.md) for usage, all input-boundary callers, reconnect
contracts and opt-in tests. `tools/check_network_build.tscn` compiles client/test
scripts without opening sockets or executing gameplay assertions.

Hover wording conventions and the user's purple Mshield asset are documented in
[HOVER_TEXT.md](HOVER_TEXT.md). `EffectText` generates these shared descriptions;
`tools/import_mshield.py` imports the icon/native nine-frame barrier. Typed
`TimedGrant` records now support recipient-bound modifier pairs as well as action
values; Jerboa King's revised Move support is the concrete caller.

Crowned heroes: `scripts/catalogue/hero_catalogue.gd` defines Grey Squirrel King,
Jerboa King and Marmot Queen as object-authored hero alternatives. Both inventory
entry points append them after older IDs. `tools/import_hero_characters.py` imports
their reviewed PixelLab animations and rebuilds runtime sheets; focused regressions
are in `tests/hero_units_test.tscn`. See [HERO_UNITS.md](HERO_UNITS.md) for card text,
caller maps and interaction examples.

Shared cursors: `scripts/ui/game_cursors.gd` installs the pixel hand and matching
text, grab, drag, accepted-drop and blocked-drop SVGs from `assets/ui/`. Both
client entry scenes call it; see [ARMY_BUILDER.md](ARMY_BUILDER.md) for callers
and usage examples, including the game's Ctrl-draggable inspection panel.

Spritesheets (2026-10-30): `assets/characters/sheets/` is the current runtime art:
one PNG per PixelLab character, atlas portrait resources and a frame/bounds
manifest. `tools/build_character_sheets.py` packs the original PNGs losslessly;
alignment/import tools also rebuild sheets. Original frames, exports and legacy
portrait directories are preserved under `.gdignore`. Board/tray art shares the
same sheet and baked metadata. See [CHARACTER_SHEETS.md](CHARACTER_SHEETS.md) for
the actual caller map, shaders, excluded folders and rebuild command.

Opt-in regression runner (2026-10-29): `tools/run_tests.py` discovers fifteen
scenes, isolates saved data, applies timeouts and records logs/results, rejecting
script/engine errors as well as failed assertions. [TESTING.md](TESTING.md) maps
coverage and the nine cross-roster chains in `tests/adventurer_synergies_test.gd`.
Run only after a request ending TEST.

Adventurers (2026-10-29): `scripts/catalogue/adventurer_catalogue.gd` defines the
twenty new class/rodent cards; `scripts/effects/adventurer_rules.gd` holds their
shared selectors, conditions, bindings and actions. Both owner blocks append to
the catalogue without changing older IDs. `tools/import_adventurer_characters.py`
installs their accepted art and bakes foot alignment. See
[ADVENTURER_UNITS.md](ADVENTURER_UNITS.md) for rules, examples, caller map and the
focused `tests/adventurer_units_test.tscn` regression scene.

Animation repair assets (2026-10-29):
`exports/repaired-character-animations/manifest.json` identifies the reviewed

See [SELECTION.md](SELECTION.md) for the playback caller map.

Wild Return additions (2026-10-26): `scripts/effects/wild_rules.gd` authors the
eight requested Wild rodents; `wild_actions.gd` owns selection-only counter-host
legality and Chinchilla's Return/redeployment action. `rule_number.gd` now binds

contain existing PixelLab standing/seated/walk/rise/action PNGs; their manifest
entries record the original source character IDs.

This guide describes the maintained files and the boundaries between them. Code
is grouped by responsibility under `scripts/`; scenes, artwork, tests, and design
documents stay in their own top-level directories. Godot `.uid` and `.import`
files belong beside their source resources and are generated by the editor.

### `scripts/board/` and `scripts/ui/` — presentation and input

Stun/charge feedback ordering: captured triggers still execute through RulesRunner
immediately, but `_present_trigger()` defers `_queue_trigger_feedback()` until
synchronous consequences have published life deltas. If that source has an
active slash, its cue waits for the slash node's exit (after the 1.5s fade cycle),
then rechecks identity/position before playing. Thus Red Squirrel Climber's Stun
charge shows its life-loss slash first, then the top-left trigger stars. Trigger
stars now repeat their eight-frame clip once (16 frames total at 8fps, 2s),
without repeating the triggered rules or changing turn timing.
Resolved Stun consequences play the nine-frame PixelLab orbiting-star clip on
the recipient, with 0.2s fade-in/final 0.35s fade-out over STUN_DURATION (1.5s).
Activity-cost self-Stun does not play this action clip. Click replays discover
`assets/effects/stun/`, play the full clip once over the same duration, and use
its shared target offset. Source object `3e1db0e2-57ed-4b39-8f3a-6efea7f00dab`,
animation group `fb3a0cfd-7ee7-4574-9d1a-991dd51c584c`.

Push/Pull use shared finite presentation in `displacement_effect.gd`:
`board_displacement.setup()` and `action_replay.setup()` call its `setup()`
with captured actor, previous target and final target hexes plus figure IDs.
The actor's separate Push/Pull icon plays once (1.2s); enlarged wind plays twice
over 2.4s, with fades. Live setup supplies a weak reference to the sliding figure:
wind follows it during the one-second translation, then stays at the landing.
Replay supplies no moving figure, so wind stays at the captured final position.
Pull reflects the wind. Neither clip loops.
Click replay uses this same pair, pulses the previous target hex rim gold and
never repeats the unit translation. For example, pulling a Bash participant
shows the icon on the actor and wind on that participant's final side.

General Bash exits: `HexCell.refresh()` detects its previous live Bash becoming
ordinary layout, regardless of whether Walk, Fly, Gore, Push/Pull, defeat or a
future effect caused it. `_begin_bash_exit()` captures side positions before
rebuilding; `_apply_bash_exit_progress()` recenters remaining figures and fades
ordinary info in over 0.8s. Stored ordinary base poses keep the transition stable
through repaint. `take_bash_departure_offset()` gives walking/displacement
presenters the departed figure's original side, with unit/destination validation;
Push/Pull slides from that side into the final ordinary/Bash pose. Survivor
recentering no longer depends on a walking overlay or Move-specific event field.

Sleeping onset: `_sync_sleeping_markers()` calls `_sleeping_feedback_ready()`.
Self-Stun waits until `BoardCharacter.is_seated_for_feedback()` confirms the
complete action/turn/sit sequence has ended; walking/displacement postpones the
first Z as well. A resolved Stun from another unit marks the recipient eligible
immediately, even before it sits. Eligibility is cleared when its Stun reaches
zero. Existing loops keep their continuous playback and final-counter fade-out.

Bash hover timing: `HexCell._set_bash_hover_side()` directly calls
`_animate_bash_focus()` for the current half, with no intermediate split/reset
pause. Unit opacity, ordinary hex info, and Bash stats/details/reveal all use
`BoardCharacter.HOVER_FADE_DURATION` (0.18s). Switching sides interrupts the
previous tween from its visible state, matching normal hovering; no delayed
focus timer can override a later pointer position.

Bash participant targeting: `GuerraBoard._on_cell_pressed()` asks
`HexCell.bash_unit_at_position()` for the live participant on the clicked half
(red Player 1 left, blue Player 2 right). UNIT selectors commit that exact
identity only if it remains in the legal candidate set, including inactive Bash
participants. Clicking an illegal half keeps the choice pending rather than
substituting the other unit. HEX-target actions still select the whole tile.
For example, Mouse Engineer's Pull can choose either legal participant of a
Bash directly; normal displacement cancels the vacated encounter and preserves
the other unit. Non-Bash ambiguity retains the existing menu fallback.
Popup `window_input` now calls `_on_choice_window_input()` instead of forwarding
pointer presses to board outside-click cancellation; Escape still cancels, while
`_on_choice_pressed()` commits the selected reference after the menu's press.

Push/Pull live animation: `CombatResolver` retains `source_hex`, recipient
`origin_hex` and `destination_hex` in the resolved displacement event.
`GuerraBoard._on_action_presentation()` repaints the logical landing, then
`_present_displacement()` → `board_displacement.gd.setup()` creates a cosmetic
copy of the target's figure. The real landing figure is hidden through
`HexCell.set_displacement_hidden()` (retained across repaint), while the copy
slides continuously from the previous hex to its actual landing/Bash side over
1s. The shared finite actor icon and two wind passes then finish automatically.
Historical replay uses displacement_effect.gd without creating a sliding copy.
Its authored left-to-right motion is rotated along the original actor-to-target
direction for Push; Pull horizontally reflects that same art before rotation,
so the gust flows toward the actor. Sleeping/feedback markers follow the sliding
copy. Completion, interruption, movement, defeat and scene exit restore the
stationary figure; no rules or movement execute a second time. Multiple actors
can displace different targets concurrently. Previous-turn replays use the same
clip/direction/final-hex placement (without moving actual troops).

Previous-turn replay caller map: `Match.action_event` →
`GuerraBoard._remember_action()` records manual action endpoints and walking
paths; `_on_cell_pressed()` → `_offer_action_replay()` → `_replay_unit_action()`
creates `scripts/board/action_replay.gd` cosmetic overlays. Only a deployed
occupant that acted on `Match.turn_number - 1` qualifies, even when enemy or
inactive. Legal effect targets and deployment selection retain priority; a

The replay rim uses the transparent `grey-hex.png` artwork with the actual
cell/frame transform, so only frame pixels are tinted and resize/target scale
remain aligned; there is no geometric outline or filled-hex highlight.

turn, and is not persisted in snapshots; triggers/self-costs and resolved attack
duplicates are excluded. Multiple recorded actions replay together.

Automatic replay extension contract: a manually executed consequence emits its
normal `EffectEvent` using `phrase.verb.name` at `target` or `resolved` stage.
`_remember_action()` matches that live consequence verb rather than maintaining
an attack-name list; costs, triggered followups and combat's later resolved
notifications are excluded. A phrase/recipient key deduplicates target/resolved
notifications while preserving different ALL recipients.

## Assets and editor support

- `assets/*.png` holds board backgrounds/hexes, combat effects, controls, and
  status icons. The filename identifies the specific displayed element.
- `assets/cards/*.png` holds the regular card illustrations; filenames match
  card IDs or shared card-art names from the catalogue.
- `assets/cards/high_resolution/*.png` holds larger alternate card illustrations
  for art sources that have them.
- `assets/shaders/inactive_board_art.gdshader` gives inactive figures the
  parchment-grayscale treatment and projects the centered vertical-axis hover squash.
- `assets/sprites/*.svg` holds scalable crown, helm, and temple interface sprites.
- `assets/move_and_resize.sh` and `assets/cards/move_and_resize.sh` are local
  image-preparation helpers for downloading/resizing artwork; they are not part
  of the runtime.
- A `.import` file beside an image is Godot's import settings/cache metadata for
  that image, not a second asset to edit by hand. A `.uid` file beside a script
  preserves its stable Godot resource identity after the file moves.
- `icon.svg` is the project icon. `godot.exe` is a local engine executable.
- `.editorconfig` sets editor encoding defaults; `.gitattributes` normalizes text
  line endings; `.gitignore` excludes generated Godot state and local tools.
- `.godot/` contains generated editor/import state and should not be hand-edited.
  `.tools/` is ignored local tooling. Empty `export_templates/`,
  `feature_profiles/`, `script_templates/`, and `text_editor_themes/` directories
  are Godot user/editor support locations, not runtime source folders.
- `scenes/board/*.tmp` files, if present, are editor temporary saves rather than
  project scenes.
